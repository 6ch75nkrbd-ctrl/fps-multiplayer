# 🎮 FPS Multiplayer

> 실시간 멀티플레이어 FPS 게임 — Node.js WebSocket 서버 + Three.js 브라우저 클라이언트

## ✨ 주요 기능

- **팀 대전**: 블루팀(나) vs 레드팀(AI 5명)
- **20개 건물** 내부 입장 가능, 가구/조명/창문 디테일
- **6종 아이템** (체력/탄약/데미지/속도/방어구/응급처치) — 건물 내/야외 스폰
- **자동차 10대** 탑승/하차, 가속·조향·충돌 물리
- **비행기 보급** — 60초마다 하늘에서 보급 상자 투하
- **헤드샷** 감지 (1.5x 데미지, 오렌지 히트마커)
- **연속 킬** 시스템 (3~8킬 배너)
- **데미지 숫자** 화면 표시
- **인벤토리** 10슬롯, 단축키 1~9
- **스코프** (우클릭 3배율), **연사+반동** 설정
- **미니맵 / 전체 지도 (M)** / **스코어보드 (Tab)** / **채팅 (Enter)**
- **실시간 60 tick** 서버 권위 처리

## 🚀 실행 방법

### 필요 사항
- Node.js 18+ (WebSocket 모듈 내장)
- npm (ws 패키지 설치용)

### 설치 & 실행

```bash
# 1. 의존성 설치
npm install

# 2. 서버 시작
node server.js

# 3. 브라우저에서 열기
# http://localhost:3000
```

포트 변경: `server.js`의 `PORT = 3000` 수정

## 🏗️ 아키텍처

```
┌─────────────────┐  WebSocket   ┌──────────────────┐
│  브라우저 클라이언트  │ ◄────────► │  Node.js 권위 서버  │
│  (Three.js 0.160) │   60Hz      │  (ws + http)     │
└─────────────────┘              └──────────────────┘
       │                                    │
   렌더링/입력                          게임 상태
   클라이언트 예측                      물리/충돌/AI
   인터폴레이션                         점수/킬/리스폰
```

- **서버 권위**: 모든 히트 판정, 점수, 데미지는 서버에서 처리
- **클라이언트 보간**: 30Hz 상태 브로드캐스트, 부드러운 보간
- **물리**: 지형 높이 함수(서버/클라 동일), 건물 AABB 충돌, 차량 원형 충돌

### GitHub Pages로 클라이언트만 호스팅 (서버 별도 필요)

2. Source: `main` branch / root
3. `index.html`의 WebSocket URL을 본인 서버 주소로 변경

## 🛠️ 기술 스택

- **서버**: Node.js, `ws` (WebSocket)
- **클라이언트**: Three.js 0.160 (CDN), 순수 JavaScript
- **프로토콜**: JSON 메시지 (60Hz 상태 동기화)
